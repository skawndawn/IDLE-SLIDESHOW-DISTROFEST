GARUDA LINUX — FACT OR CAP OFFLINE BOOTH GAME

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, etc.
3. Internet is NOT required.
4. Enter a player name and press START CHALLENGE.

FEATURES:
- 200-question IT/Linux/Garuda question pool
- Exactly 5 random questions per player
- FACT or MYTH choice for every question
- Correct/wrong sound effects generated by the browser
- Final score after question 5
- Perfect 5/5 celebration with confetti
- Try again / better luck next time messages
- Local leaderboard using browser localStorage
- No external libraries, fonts, APIs, or network requests

IMPORTANT:
The leaderboard is stored only on that specific browser/device. Clearing browser site data resets it.
